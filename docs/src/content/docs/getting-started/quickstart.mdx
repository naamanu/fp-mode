This guide walks you through the full workflow — browsing problems, writing a solution, and submitting it for judging.

## 1. Browse Problems

```bash
fp-mode list
```

```
  ○  reverse-list          easy     recursion              haskell, ocaml
  ○  map-from-scratch      easy     higher-order-functions haskell, ocaml
  ○  binary-tree-depth     medium   recursion              haskell, ocaml
  ○  flatten-nested-list   medium   recursion              haskell, ocaml
  ○  state-monad-counter   hard     monads                 haskell
```

Filter by difficulty:

```bash
fp-mode list --difficulty easy
```

## 2. Start a Problem

```bash
fp-mode start reverse-list
```

This creates a workspace at `~/.fp-mode/workspace/reverse-list/Solution.hs` with starter code:

```haskell
module Solution (reverseList) where

-- | Reverse a list using recursion.
-- Do not use the built-in reverse function.
reverseList :: [a] -> [a]
reverseList = undefined
```

Your configured editor opens automatically. If it doesn't, open the file manually.

:::tip
Set your preferred editor with the `EDITOR` environment variable:
```bash
export EDITOR="code --wait"  # VS Code
export EDITOR="nvim"         # Neovim
```
:::

## 3. Write Your Solution

Replace `undefined` with your implementation:

```haskell
module Solution (reverseList) where

reverseList :: [a] -> [a]
reverseList [] = []
reverseList (x:xs) = reverseList xs ++ [x]
```

## 4. Submit

```bash
fp-mode submit reverse-list
```

## Interactive TUI

You can also launch the interactive terminal UI:

```bash
fp-mode
```

Use keyboard shortcuts to navigate:
- **↑/↓** or **j/k** — move cursor
- **Enter** — view problem
- **e** — open in editor
- **s** — submit solution
- **l** or **Tab** — switch language
- **1/2/3** — filter by difficulty
- **q** — quit

## Using OCaml

To work in OCaml instead of Haskell:

```bash
fp-mode start reverse-list --lang ocaml
fp-mode submit reverse-list --lang ocaml
```

The starter code will be in `solution.ml`:

```ocaml
let rec reverse_list = function
  | [] -> []
  | x :: xs -> reverse_list xs @ [x]
```
